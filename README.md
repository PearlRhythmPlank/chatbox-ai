# Chatbox AI

### Desktop client for all major AI models

Chatbox AI is a desktop application that gives you a clean, powerful interface for interacting with GPT-4, Claude, Gemini, local models, and any OpenAI-compatible API — with conversation history, markdown rendering, and more.

<br>

---

## Features

| | |
|:---|:---|
| **Multi-Model** | Switch between OpenAI, Anthropic, Google, Mistral, and local models |
| **Conversation History** | All chats saved locally with full search and organization |
| **Markdown & Code** | Rich rendering for code blocks, math formulas, and formatted text |
| **Cross-Platform** | Available for Windows, macOS, and Linux |
